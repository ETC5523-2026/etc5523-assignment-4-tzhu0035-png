# The 15 activity categories

How the several hundred detailed ATUS activity codes were grouped into
15 everyday categories.

## Usage

``` r
activity_categories
```

## Format

A tibble with 15 rows and 3 columns:

- category:

  Short name used in the data and functions.

- label:

  Readable name used in the app.

- description:

  What the category includes.

## Source

Based on the ATUS 2025 Activity Coding Lexicon,
<https://www.bls.gov/tus/lexicons/lexiconnoex2025.pdf>.
