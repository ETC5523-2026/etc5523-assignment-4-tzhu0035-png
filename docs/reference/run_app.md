# Launch the "Whose Day Is It?" Shiny app

Opens the interactive app that ships with the package. Enter how you
spent a day, and the app finds the day types from the 2025 American Time
Use Survey that look most like it.

## Usage

``` r
run_app()
```

## Value

Called for its side effect of launching the app.

## Examples

``` r
if (interactive()) {
  run_app()
}
```
